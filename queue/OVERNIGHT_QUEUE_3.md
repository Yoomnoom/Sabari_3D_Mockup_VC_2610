### 작업 19. 임시저장 알림을 상단 띠에서 3D 화면 안으로 (task/19-draft-toast)
- 상단 초록 띠를 제거하고(DOM id가 있으면 기존 e2e 호환 확인) 3D 화면 안 왼쪽 아래 떠 있는 알림으로(position absolute, 레이아웃을 밀지 않음, 바닥에서 약 84px, 왼쪽 16px, 최대 폭 350px, 흰 배경, 왼쪽 초록 선, 둥근 모서리, 그림자).
- 내용: 제목 "이전 임시저장이 있습니다", 본문 "<날짜 시각>에 자동 보관된 작업입니다.", 버튼 [불러오기](주황) [닫기]. "왼쪽 아래 ..." 안내 삭제.
- 동작: [불러오기]는 기존 임시저장 불러오기 함수(저장하지 않은 변경이 있으면 기존 확인 대화상자). [닫기]는 알림만 닫고 임시저장 유지, 이 세션에서 다시 띄우지 않음. 12초 뒤 자동으로 사라지되 호버·포커스 중에는 유지. 사라진 뒤에도 "열기" 메뉴의 "임시저장 불러오기" 줄에 날짜와 작은 주황 점(불러오거나 새 임시저장이 생기면 제거). 내보내기 탭의 임시저장 상태 줄은 그대로.
- 표시 조건: 앱을 열 때 임시저장이 있을 때만. 외부 GLB 중에는 표시하지 않고 돌아간 뒤 표시. 프로젝트를 열었거나 임시저장을 불러온 직후에는 표시하지 않음.
- 모바일(900px 미만): 3D 영역 안, 작업 시트 바로 위 폭 약 90%. 접근성: role="status" aria-live="polite", 포커스 비탈취, Tab으로 두 버튼, 포커스에서 Esc로 닫힘, 텍스트 라벨.
- 같은 종류의 다른 상단 알림 띠를 찾아 목록만 보고(바꾸지 않음).
- 검증(합성): 알림 전후 3D 캔버스 크기·위치 불변, 스크롤바 없음, 창 4종(1920×1080, 1366×768, 1024×768, 390×844)에서 플로팅 바·시트와 겹치지 않음, 각 동작, .sabari·임시저장 형식 불변. 의존하던 e2e를 고쳤다면 이유 기록.

### 작업 20. 깨끗한 화면(녹화용) 모드 (task/20-clean-screen)
- 켜면 3D 캔버스를 제외한 모든 UI를 숨긴다: 상단 바, 왼쪽 탭과 패널, 오른쪽 "선택한 면" 패널, 하단 플로팅 메뉴, 회전 각도 배지(드래그 중 임시 배지 포함), 임시저장 알림, 외부 GLB 띠, 면 선택선(주황), 축 잠금의 회전축 선과 하이라이트, 확대경, 모바일 작업 시트와 하단 탭 바. 배경·그림자·음영·알파 마스크 보기 등 렌더 설정은 유지. 캔버스는 창 전체로 넓어지고 박스가 잘리지 않는다(기존 resize 안정화 코드 보존, 페이지 스크롤·가로 스크롤바 금지, 피드백 루프 금지).
- 진입: 단축키 H(충돌하면 다른 키를 고르고 기록)와 ⋮ 더보기 "깨끗한 화면(녹화용)". 해제: 같은 키와 Esc. Esc는 "단축키 사용"이 꺼져 있어도 항상 해제하며 이 모드에서 다른 Esc 동작보다 우선. 켜고 끌 때 안내를 띄우지 않는다. 터치 기기에서는 오른쪽 위 모서리 1초 길게 누르면 해제(시각 표시 없음).
- 모드 중 마우스·터치 회전, 휠 확대, Space 이동, 시점 단축키(1, 3, 7, R, L, F, 0, Alt+숫자, O)는 그대로 동작. 면 클릭 편집 선택은 하지 않는다. 숨겨진 UI의 단축키 결과 알림이 3D 위에 뜨지 않게 한다.
- 저장하지 않고 항상 보통 화면으로 시작. PNG·GLB는 보통 화면과 같고, 해제하면 직전 UI 상태(활성 탭, 패널 접힘, 스크롤)가 복원된다.
- ⋮ 더보기에 개별 설정 2개: "회전 각도 배지 보기", "하단 플로팅 메뉴 보기"(기본 켜짐, localStorage만, 끄면 시점 단축키와 보기 탭 버튼은 그대로 사용 가능). 도움말에 H와 Esc 추가. 작업 22가 병합되어 있으므로 모드 중에는 축 선 설정과 무관하게 숨기고 해제하면 사용자 설정으로 복원.
- 3D 화면에 겹쳐 뜨는 다른 요소를 전부 찾아 목록으로 보고하고 이 모드에서 숨겨지는지 확인.
- 검증(합성): 켠 상태에서 캔버스 외 보이는 요소 0(DOM과 스크린샷 픽셀), 선택선 픽셀 없음, 창 4종에서 캔버스가 창 전체를 채우고 스크롤바 없음, 진입·해제 전후 카메라·자세·선택 면·컨트롤 값·활성 탭 동일, H·Esc·더보기 항목·단축키 끈 상태 Esc, 모드 중 시점 단축키와 회전, 개별 설정 2개와 새로고침 후 유지, 터치 길게 누르기 해제(합성 터치), 외부 GLB 중 동작, PNG·GLB 불변(GLB validator 0/0).
