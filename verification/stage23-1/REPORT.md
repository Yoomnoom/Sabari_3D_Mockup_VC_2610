## 구현 결과

- 보기 UI는 시점·박스 놓기·축 고정 세 줄이다. 텍스트 라벨과 `aria-pressed`로 상태를 표시한다.
- 눕힘은 단계 17과 같은 자세다. 세움은 화면 전용 pivot이며 원본 root 행렬은 identity로 유지됐다.
- 세움의 lid_top 법선은 `[0,0,1]`, 165mm 긴 변은 `[0,1,0]`; 뚜껑 열림 80mm의 월드 이동은 `[0,0,0.08]`이다.
- 좌우만 대각선 드래그 후 고도 변화는 0, 반복 회전 후 긴 변의 화면 가로 편차는 `4.98e-18`이다. 위아래만은 방위각 변화 0, 상·하한 ±89°다.
- 자세 전후 같은 편집 모델을 내보낸 GLB의 SHA-256은 동일하다. `.sabari`와 임시저장에는 자세·축 고정 키가 없고 localStorage 복원은 통과했다.
